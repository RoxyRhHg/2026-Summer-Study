# 软阈值分析

这篇笔记只解决一个问题：

> 为什么近端梯度处理 $\ell_1$ 正则时，会自然地产生`软阈值`，而且为什么小系数会精确变成 $0$？

它直接承接 [[近端梯度为什么自然出现]]：前一篇已经得到近端子问题，这里继续追问这个子问题在 $g(x)=\lambda\lVert x\rVert_1$ 时到底怎样求。

## 从哪里开始：梯度步以后为什么还要再处理一次

考虑经典复合优化问题

$$\min_x f(x)+\lambda\lVert x\rVert_1.$$

其中：

- $f(x)$是光滑的数据拟合项；
- $\lambda\lVert x\rVert_1$是结构项，希望解具有稀疏性；
- $x$是优化变量；
- $\lambda>0$控制稀疏正则的强弱。

近端梯度先对光滑项做一次梯度更新：

$$z=x_k-\frac1L\nabla f(x_k).$$

这个 $z$ 可以理解为：

> 如果暂时只考虑数据拟合项 $f$，下一步最想去的位置。

但 $z$ 一般并不稀疏，所以还必须把 $\ell_1$ 结构重新放回来。于是下一步不是直接取 $z$，而是解

$$x_{k+1}=\operatorname*{argmin}_x\left\{\frac12\lVert x-z\rVert_2^2+\frac\lambda L\lVert x\rVert_1\right\}.$$

这个问题同时包含两股力量：

- $\frac12\lVert x-z\rVert_2^2$：不要离梯度步结果 $z$ 太远；
- $\frac\lambda L\lVert x\rVert_1$：希望 $x$ 的绝对值尽可能小，并最终产生稀疏结构。

所以软阈值本质上是在解决：

$$\text{尽量靠近 }z\quad\longleftrightarrow\quad\text{尽量靠近 }0.$$

## 为什么可以把向量问题拆成一维问题

记

$$\tau=\frac\lambda L.$$

由于

$$\lVert x-z\rVert_2^2=\sum_i(x_i-z_i)^2,$$

并且

$$\lVert x\rVert_1=\sum_i\lvert x_i\rvert,$$

整个目标可以按坐标完全拆开。因此每一个坐标都只需要独立求解

$$\min_u\left\{\frac12(u-v)^2+\tau\lvert u\rvert\right\},$$

其中 $v$ 是梯度步结果 $z$ 的某一个坐标，$u$ 是这一坐标经过近端修正后的新值。

所以真正要理解的核心问题只有一维：

> 已知梯度步希望我去 $v$，但 $\ell_1$ 又希望我靠近 $0$，最后应该停在哪里？

## 如果没有 $\ell_1$ 正则会怎样

若 $\tau=0$，问题退化成

$$\min_u\frac12(u-v)^2.$$

最优解就是

$$u=v.$$

也就是说，没有结构项时，完全接受梯度步给出的结果。

加入 $\tau\lvert u\rvert$ 后，情况才发生变化。

## 当 $v>0$：为什么会向 $0$ 缩小一个 $\tau$

先假设最终最优解满足 $u>0$。此时

$$\lvert u\rvert=u,$$

目标变成

$$\phi(u)=\frac12(u-v)^2+\tau u.$$

求导：

$$\phi'(u)=u-v+\tau.$$

令导数为 $0$：

$$u=v-\tau.$$

这说明，如果最优解仍然位于正半轴，$\ell_1$ 正则会把原来的梯度步结果

$$v$$

向 $0$ 拉回固定距离

$$\tau.$$

也就是

$$v\rightarrow v-\tau.$$

这就是`shrinkage（收缩）`。

例如 $v=5,\tau=2$ 时，最终得到 $u=3$。

## 为什么小的正数不会穿过 $0$ 变成负数

真正关键的地方出现在

$$0<v<\tau.$$

如果机械套用上一节公式，会得到

$$u=v-\tau<0,$$

但刚才推导这一公式时假设的是 $u>0$，所以这个结果已经离开了自己的适用区域。

那么会不会真正的最优点跑到负半轴？

假设 $u<0$，则

$$\lvert u\rvert=-u,$$

目标变成

$$\phi(u)=\frac12(u-v)^2-\tau u.$$

求导：

$$\phi'(u)=u-v-\tau.$$

令其为 $0$：

$$u=v+\tau.$$

但当 $v>0$ 时，$v+\tau>0$，又与假设 $u<0$ 冲突。

因此当 $0<v<\tau$ 时：

- 正半轴内部没有合法极小点；
- 负半轴内部也没有合法极小点；
- 两个区域的交界点只剩下 $u=0$。

所以最优解只能是

$$u=0.$$

这就是“阈值”真正出现的原因。

## 当 $v<0$：完全对称

若最终 $u<0$，则

$$\lvert u\rvert=-u.$$

目标为

$$\phi(u)=\frac12(u-v)^2-\tau u.$$

求导并令其为 $0$：

$$u-v-\tau=0,$$

所以

$$u=v+\tau.$$

例如 $v=-5,\tau=2$ 时，得到

$$u=-3.$$

也就是说，负数同样会向 $0$ 收缩一个距离 $\tau$。

如果 $-\tau\le v<0$，按照同样的区域一致性分析，最优解落在

$$u=0.$$

## 三种情况合起来就是软阈值

最终一维解为

$$S_\tau(v)=\begin{cases}v-\tau,&v>\tau,\\0,&\lvert v\rvert\le\tau,\\v+\tau,&v<-\tau.\end{cases}$$

也可以写成更紧凑的形式

$$S_\tau(v)=\operatorname{sign}(v)\max\{\lvert v\rvert-\tau,0\}.$$

因此软阈值的动作可以直接读成：

- $\lvert v\rvert\le\tau$：证据太弱，直接压成 $0$；
- $v>\tau$：保留正号，但向 $0$ 缩小 $\tau$；
- $v<-\tau$：保留负号，但同样向 $0$ 缩小 $\tau$。

例如取 $\tau=2$：

| $v$ | $S_2(v)$ |
| --- | --- |
| $5$ | $3$ |
| $2.5$ | $0.5$ |
| $2$ | $0$ |
| $1$ | $0$ |
| $-1$ | $0$ |
| $-2$ | $0$ |
| $-2.5$ | $-0.5$ |
| $-5$ | $-3$ |

## 为什么叫“软”阈值，而不是硬阈值

`硬阈值`通常表示

$$H_\tau(v)=\begin{cases}v,&\lvert v\rvert>\tau,\\0,&\lvert v\rvert\le\tau.\end{cases}$$

它的规则是：

> 小的直接删掉，大的完全不动。

而软阈值即使决定保留某个分量，也仍然把它向 $0$ 收缩：

$$5\rightarrow3$$

而不是

$$5\rightarrow5.$$

所以“软”的含义不是阈值不明确，而是`超过阈值后仍然连续收缩，而不是原样保留`。

## 为什么 $\ell_1$ 能产生精确的 $0$

这一点是软阈值最值得理解的地方。

$\ell_2$ 正则也会把参数向 $0$ 拉，但一般只是缩小，很少把一整段输入直接映射成精确的 $0$。$\ell_1$ 不同，关键在于

$$\lvert u\rvert$$

在 $u=0$ 处有尖点，不可微。

更严格地，用次梯度写一维最优性条件：

$$0\in u-v+\tau\partial\lvert u\rvert.$$

当 $u=0$ 时，

$$\partial\lvert 0\rvert=[-1,1].$$

因此 $u=0$ 成为最优解的条件是

$$0\in -v+\tau[-1,1].$$

这等价于

$$v\in[-\tau,\tau],$$

也就是

$$\lvert v\rvert\le\tau.$$

这说明不是“刚好某一个 $v$”映射到 $0$，而是一整段输入

$$[-\tau,\tau]$$

都会被压到同一个点 $0$。

这正是 $\ell_1$ 正则能够产生稀疏解的数学来源。

## 把软阈值重新接回近端梯度

对于

$$F(x)=f(x)+\lambda\lVert x\rVert_1,$$

近端梯度一步为

$$x_{k+1}=\operatorname{prox}_{(\lambda/L)\lVert\cdot\rVert_1}\left(x_k-\frac1L\nabla f(x_k)\right).$$

而 $\ell_1$ 范数的 prox 恰好就是软阈值，所以

$$x_{k+1}=S_{\lambda/L}\left(x_k-\frac1L\nabla f(x_k)\right).$$

这时可以把一次更新理解成两个角色：

- 梯度步回答：`如果只考虑数据一致性，我应该去哪里？`
- 软阈值回答：`这个分量的证据是否强到值得保留下来？如果保留，应该收缩多少？`

若某个梯度步后的分量满足

$$\lvert z_i\rvert\le\frac\lambda L,$$

它就直接变成 $0$；若超过阈值，则保留符号并向 $0$ 收缩 $\lambda/L$。

这也是 [[1 FISTA（讲解版）#四、当$g(x)=\lambda\lVert x\rVert_1$时，为什么出现软阈值|FISTA 中软阈值步骤]] 的具体来源。

## 核心记忆

软阈值不是人为规定的“把小数删掉”规则，而是下面这个凸优化子问题的精确解：

$$\min_u\left\{\frac12(u-v)^2+\tau\lvert u\rvert\right\}.$$

它的因果链是：

$$\ell_1\text{正则}\rightarrow\text{近端子问题}\rightarrow\text{一维绝对值优化}\rightarrow\text{软阈值}\rightarrow\text{稀疏}.$$

真正该记住的是：`梯度步给出临时位置，$\ell_1$ 的 prox 再把它向 $0$ 拉；拉力足以跨过阈值时，最优解不会越过 $0$，而是直接停在 $0$。`
