# PnP-ADMM 思维导图

> [!cite] Zotero 资料基线
> - [[Boyd 等 - 2011 - Distributed Optimization and Statistical Learning via the Alternating Direction Method of Multipliers|Boyd 等 2011：ADMM]] · [Zotero](zotero://select/library/items/B7AYLH4I)
> - [[Chan 等 - 2017 - Plug-and-Play ADMM for Image Restoration - Fixed Point Convergence and Applications|Chan 等 2017：PnP-ADMM]] · [Zotero](zotero://select/library/items/2HLFYW77)

## 起点

- `逆问题`：$\min_x f(x)+\lambda g(x)$
  - $f$：数据一致性 / forward model
  - $g$：显式图像先验
  - 困难：denoiser $\mathcal D_\sigma$是`图像→图像`映射，不能直接和标量$f(x)$相加
- `PnP 需求`：寻找一个原本就具有“先验图像处理接口”的算法骨架

## ADMM 分裂

- `一致性分裂`：$\min_{x,v}f(x)+\lambda g(v)$，约束$x=v$
  - $x$：数据变量
  - $v$：先验变量
  - $u$：scaled dual variable，累计$x-v$分歧
- `scaled ADMM`
  - 数据步：$x^{k+1}=\arg\min_x f(x)+(\rho/2)\lVert x-(v^k-u^k)\rVert_2^2$
  - 先验步：$v^{k+1}=\arg\min_v \lambda g(v)+(\rho/2)\lVert v-(x^{k+1}+u^k)\rVert_2^2$
  - 协调步：$u^{k+1}=u^k+x^{k+1}-v^{k+1}$

## 去噪接口

- 定义$\sigma=\sqrt{\lambda/\rho}$
- 先验步等价于：$v^{k+1}=\arg\min_v g(v)+(1/2\sigma^2)\lVert v-(x^{k+1}+u^k)\rVert_2^2$
- 结构：`先验代价 + 不离输入太远` → proximal denoising
- `PnP 替换`：$v^{k+1}=\mathcal D_{\sigma_k}(x^{k+1}+u^k)$
- $\sigma_k$：denoiser 强度旋钮；不必等于迭代扰动的真实 Gaussian 标准差

## 理论断点

- 经典 ADMM：显式$f,g$ + convex/saddle-point 条件 → residual / objective / dual convergence
- PnP：一般$\mathcal D_\sigma$未必是某个$g$的 prox
- 不能自动推出：`PnP 仍在最小化某个显式$f+\lambda g$`
- 新目标：`优化最优性`暂时退到`fixed-point stability`

## Bounded denoiser

- 条件：$\lVert\mathcal D_\sigma(x)-x\rVert_2^2/n\le\sigma^2C$
- 含义：限制`一次去噪改多远`
- $\sigma\to0\Rightarrow\mathcal D_\sigma\to I$
- 易混：
  - bounded：单输入$x$与输出$\mathcal D(x)$的距离
  - nonexpansive：两个输入$x,y$经过映射后的距离不放大
- 单独 bounded 不够：若$\sigma$固定，单步上界固定，不能保证无限轮总移动量有限

## Continuation

- 关系：$\rho_{k+1}=\gamma_k\rho_k$，$\sigma_k=\sqrt{\lambda/\rho_k}$
- `增大$\rho_k$`：$\sigma_k\downarrow$，denoiser 更接近$I$；数据步也更贴近当前共识
- 状态增量：$\Delta_{k+1}=(\lVert\Delta x\rVert_2+\lVert\Delta v\rVert_2+\lVert\Delta u\rVert_2)/\sqrt n$
- 自适应两机制：
  - $\Delta_{k+1}\ge\eta\Delta_k$ → 增大$\rho_k$ → 相邻状态受$O(1/\sqrt{\rho_k})$控制
  - $\Delta_{k+1}<\eta\Delta_k$ → 保持$\rho_k$ → 状态增量已几何收缩
- 关键：不是简单要求自适应情形下$\rho_k$必然趋于无穷，而是`无论哪个分支都让状态增量可控并持续变小`

## Fixed point

- 状态：$\theta^k=(x^k,v^k,u^k)$
- 证明链：$D(\theta^{k+1},\theta^k)\le C\delta^k$，$0<\delta<1$ → 增量可求和 → Cauchy → $\theta^k\to\theta^\star$
- 一致性：$u^{k+1}-u^k=x^{k+1}-v^{k+1}\to0$ → $x^k-v^k\to0$
- 边界：`fixed point` $\neq$ `未知显式目标的全局最优点` $\neq$ `最好重建质量`

## 停止判据

- `经典 ADMM`：primal residual $r^{k+1}=x^{k+1}-v^{k+1}$ + dual residual
- `PnP fixed point`：监测$\Delta_{k+1}$是否足够小
- 区别：前者连到显式最优性条件；后者连到“状态是否停止变化”

## 参数角色

- $\lambda$：先验权重
- $\rho_k$：一致性罚参数 / continuation 参数
- $\sigma_k=\sqrt{\lambda/\rho_k}$：denoiser 强度
- $u$：数据模块与先验模块的历史分歧

## 逆问题接口

- 若$f(x)=\frac12\lVert Ax-y\rVert_2^2$：$(A^TA+\rho_kI)x^{k+1}=A^Ty+\rho_k(v^k-u^k)$
- 换 forward model → 主要重写$x$数据步
- 换 denoiser → 主要替换$v$先验步
- 主讲解：[[0 PnP-ADMM（讲解版）]]
- 下一步：数据子问题可能较重；若$f$光滑，可转向[[0 PnP-FISTA（讲解版）]]的`梯度 + denoiser + momentum`
