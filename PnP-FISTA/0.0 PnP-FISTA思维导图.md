# 0.0 PnP-FISTA 思维导图

> [!cite] Zotero 资料基线
> - [[Gavaskar 等 - 2021 - On Plug-and-Play Regularization using Linear Denoisers|Gavaskar et al. 2021]] · [Zotero](zotero://select/library/items/R3JAW5G3)
> - [[Sinha 等 - 2024 - FISTA Iterates Converge Linearly for Denoiser-Driven Regularization|Sinha & Chaudhury 2024]] · [Zotero](zotero://select/library/items/IJAI4UMU)

## 父算法

- `复合优化`：$\min_x f(x)+g(x)$
- `FISTA`：
  - 梯度：$z_k=y_k-\gamma\nabla f(y_k)$
  - prox：$x_k=\operatorname{prox}_{\gamma g}(z_k)$
  - 动量：$y_{k+1}=x_k+\alpha_k(x_k-x_{k-1})$
  - Beck–Teboulle：$\alpha_k=(t_k-1)/t_{k+1}\to1$
- 前置：[[1 FISTA（讲解版）]]

## PnP 替换

- `核心`：$\operatorname{prox}_{\gamma g}\to\mathcal D$
- `PnP-FISTA`：$x_k=\mathcal D(y_k-\gamma\nabla f(y_k))$
- $f$：forward model / data fidelity
- $\mathcal D$：图像 denoiser
- `风险`：一般 denoiser 未必是 prox，不能自动声称仍在最小化 $f+g$
- 详见 [[1 从FISTA到PnP-FISTA]]

## scaled proximal map

- `H-范数`：$\lVert x\rVert_H=\sqrt{x^THx}$，$H\succ0$
- `scaled prox`：$\operatorname{prox}_{g,H}(y)=\arg\min_x\frac12\lVert x-y\rVert_H^2+g(x)$
- `Gavaskar 2021`：线性 $W$ 是某个凸函数的 scaled prox，当且仅当其满足论文的相似变换/谱条件
- `kernel denoiser`：$W=D^{-1}K$ → $D$-scaled prox
- `对称特例`：$H=I$ → 标准 Euclidean prox
- 详见 [[2 线性denoiser与scaled proximal map]]

## scaled PnP-FISTA

- `必须同步改梯度`：$x_{k+1}=\mathcal D(y_{k+1}-\rho^{-1}H^{-1}\nabla f(y_{k+1}))$
- `H-smooth`：$\lVert H^{-1}\nabla f(x)-H^{-1}\nabla f(y)\rVert_H\le\rho\lVert x-y\rVert_H$
- `目标解释`：$\mathcal D=\operatorname{prox}_{\Phi,H}$ → 可重新对应显式凸目标 $f+g$
- `目标值速率`：$F(x_k)-F^\star=O(1/k^2)$
- `迭代点补充`：改用 $t_{k+1}=1+k/a$、$a>2$ 可得到迭代点收敛，但此处没有线性速率结论
- 详见 [[3 scaled PnP-FISTA与目标值收敛]]

## 线性迭代收敛

- `Sinha 2024`：$f(x)=\frac12\lVert Ax-b\rVert_2^2$，固定线性 denoiser $W$
- `核心假设`：
  - $\sigma(W)\subset[0,1]$
  - $\ker(A)\cap\operatorname{fix}(W)=\{0\}$
  - $\alpha_k\to1$
- `步长`：$0<\gamma<1/\lambda_{\max}(A^TA)$
- `升维状态`：$z_k=[x_k;x_{k-1}]\in\mathbb R^{2n}$
- `谱判据`：$R_k\to R_\infty$ 且 $\rho(R_\infty)<1$
- `结论`：$\lVert x_k-x^\star\rVert\le C\beta^k$，$0\le\beta<1$
- `非对称 NLM`：改在 $D$-weighted 几何中运行 scaled PnP-FISTA
- 详见 [[4 PnP-FISTA的线性迭代收敛与谱分析]]

## 两种“快”

| 结论 | 衡量对象 | 条件范围 |
| --- | --- | --- |
| FISTA / scaled PnP-FISTA 的 $O(1/k^2)$ | $F(x_k)-F^\star$ | 能恢复显式 convex objective 的情形 |
| Sinha 2024 的 linear convergence | $\lVert x_k-x^\star\rVert$ | 线性 inverse problem + 特定线性 denoiser + 谱条件 |

## 与 PnP-ADMM

- `PnP-FISTA`：梯度 + denoiser + momentum；通常每轮轻；要求 $f$光滑
- `PnP-ADMM`：data subproblem + denoiser + dual；对 $f$更通用；data step 可能更贵
- 两者共同风险：denoiser 替换后，父算法的显式目标解释不能无条件保留
- 对照：[[0 PnP-ADMM（讲解版）]]

## 易混点

- `objective acceleration` $\neq$ `iterate acceleration`
- `fixed point` $\neq$ `显式目标最优点`
- `线性 denoiser 理论` $\neq$ `任意 CNN denoiser 理论`
- `scaled`意味着换内积几何，不能只换 denoiser、不换梯度
- guide image 前几轮可更新；严格线性收敛分析针对冻结后的固定 $W$
