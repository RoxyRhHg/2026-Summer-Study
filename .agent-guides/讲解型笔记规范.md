# 整章串联讲解笔记规范

> [!important] 适用范围
> 仅当根目录 `AGENTS.md` 已判定当前任务涉及整章串联讲解笔记时应用。本文件负责“怎么讲”，不负责决定长篇模式、子 Agent 调度或资料来源。冲突时以根目录 `AGENTS.md` 为准。

## 1. 基本定位

讲解版负责回答：

- 本章为什么这样展开；
- 前一部分为什么引出后一部分；
- 一个公式或模型为什么这样建立；
- 不同知识点之间有什么因果关系；
- 方法之间如何选择；
- 本章知识如何形成统一理解。

目标是：

`易懂、连续、有主线，但不堆砌`

核心尺度：

`完整但不重复，掰碎但不拖沓。`

## 2. 每个教材一级小节围绕一个核心问题

推荐组织：

`核心问题 → 统一模型 / 母式 → 关键推导 → 模型分支 → 必要补充 → 极短过渡`

避免大量同级标题都写成：

- 为什么……；
- 再来看……；
- 从哪里来……；
- 为什么还要……；
- 这次又为什么……。

标题只承担真正的知识转折。

## 3. 先问题意识，再进入数学

讲解一个设计、定义或公式时，优先回答：

- 原问题哪里困难；
- 为什么需要新的构造；
- 这个构造直觉上在做什么；
- 数学上怎样得到；
- 最后解决了什么。

不要一上来只给公式，也不要把“问题意识”写成长篇背景故事。

## 4. 同一个原理只完整推一次

如果多个模型共用同一母式，应第一次完整解释，后续只讲新增差异。

例如多个噪声模型都来自：

$\phi(r)=-\log p(r)$

第一次可以完整说明：

`IID → 联合似然 → 对数 → 负对数似然 → penalty`

后续 Gaussian / Laplace / Uniform 重点写：

- 分布假设改变了什么；
- 损失变成什么；
- 对鲁棒性或约束有什么影响；
- 是否产生新的凸结构。

不要每个模型都重复完整联合似然推导。

## 5. 相似模型优先讲差异

后续模型重点回答：

- 新增了什么；
- 与前面相比哪里改变；
- 为什么需要这个模型；
- 它带来了什么新的数学结构。

适合比较的内容优先用表格，例如：

- Gaussian / Laplace / Uniform；
- D / E / A optimal；
- ML / MAP；
- Chebyshev / Chernoff；
- 参数估计 / 非参数估计。

表格用于比较，不用于塞长篇推导。

## 6. 推导逐步，但只展开决定理解的步骤

重点保留：

- 为什么这样变形；
- 决定凸性的步骤；
- 为什么换变量；
- 为什么某个约束是凸的；
- 为什么某个模型自然出现；
- 用户真正卡住的代数或逻辑跳步。

可以压缩：

- 纯代数重复；
- 已经在知识点型笔记中完整存在、且对当前主线无新增作用的计算。

必要时通过 `[[双链]]` 承接。

## 7. 标题不能过碎

局部“为什么”若只需要一两段，直接写正文，不要全部做成三级或四级标题。

一篇讲解版应读起来像一条连续的推理链，而不是几十个互不相干的小问答拼接。

## 8. 禁止多重重复总结

避免：

`正文讲一遍 → 节末再完整讲一遍 → 最短记忆链再讲一遍 → 全章总结再讲一遍`

节末最多保留 1—3 条真正用于承接下一节的结论。

全章最后统一收束一次即可。

重复判断标准：

> 如果删掉某段后，结论没有丢失、理解没有断裂、前后仍然顺畅，则该段大概率属于重复内容，应删除或合并。

## 9. 与其他三类笔记分工

- 定义、条件、完整公式清单主要由知识点型承载；
- 连续因果解释主要由讲解版承载；
- 快速定位和高密度回顾交给思维导图；
- 单一局部卡点优先拆为碎片问答。

讲解版不应为了“完整”复制知识点型全文。

## 10. 当前实践基准

当前参考：

`凸优化/7 统计估计/7 统计估计（讲解版）.md`

该版本从早期的：

- 内容堆砌；
- 同一逻辑反复出现；
- 标题过碎；
- 相似模型重复推导；
- 正文、节末、全章多重总结；

调整为：

- 每节一个核心问题；
- 统一原理先出现；
- 模型只讲新增点；
- 减少重复总结；
- 主干与补充分层。

复用这种方法，不复制其具体章节标题。

## 11. 完成前自检

- 是否看得出每节核心问题；
- 是否有一条连续主线；
- 同一母式是否只完整推导一次；
- 相似模型是否优先比较差异；
- 标题是否过碎；
- 是否存在正文 / 节末 / 全章重复总结；
- 是否“内容必要但层级堆砌”；
- 是否真正做到 `完整但不堆砌`。
