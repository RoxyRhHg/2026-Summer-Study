# PnP-FISTA 思维导图

> [!cite] Zotero 资料基线
> - [[Gavaskar 等 - 2021 - On Plug-and-Play Regularization using Linear Denoisers|Gavaskar 等 2021]] · [Zotero](zotero://select/library/items/R3JAW5G3)
> - [[Sinha 等 - 2024 - FISTA Iterates Converge Linearly for Denoiser-Driven Regularization|Sinha 与 Chaudhury 2024]] · [Zotero](zotero://select/library/items/IJAI4UMU)

## 起点

- [[0 PnP-ADMM（讲解版）|PnP-ADMM]]：可插 denoiser，但$x$数据子问题可能较重
- 若$f$光滑：FISTA 提供`梯度 + prox + momentum`的一阶骨架
- 目标：保留梯度和动量，只把先验 prox 换成 denoiser

## PnP 替换

- FISTA：
  - 外推：$y_k=x_{k-1}+\alpha_{k-1}(x_{k-1}-x_{k-2})$
  - 数据步：$z_k=y_k-\gamma\nabla f(y_k)$
  - 先验步：$x_k=\operatorname{prox}_{\gamma g}(z_k)$
- PnP-FISTA：$x_k=\mathcal D(y_k-\gamma\nabla f(y_k))$
- 理论断点：一般$\mathcal D$未必是 prox → 不能自动继承显式目标与$O(1/k^2)$

## Scaled prox

- 标准 prox：$\operatorname{prox}_g(y)=\arg\min_x g(x)+(1/2)\lVert x-y\rVert_2^2$
- $H$-几何：$\langle x,y\rangle_H=x^THy$，$\lVert x\rVert_H=\sqrt{x^THx}$，$H\succ0$
- scaled prox：$\operatorname{prox}_{g,H}(y)=\arg\min_x g(x)+(1/2)\lVert x-y\rVert_H^2$
- Gavaskar 2021：一类线性$W$可成为某个凸$g$的 scaled prox
- kernel denoiser：$W=D^{-1}K$ → 可取$H=D$
- 含义：`非对称于 Euclidean 几何`不等于`不存在 convex proximal 解释`

## Scaled gradient

- $H$-局部模型：$f(y)+\langle\nabla f(y),x-y\rangle+(\rho/2)\lVert x-y\rVert_H^2+g(x)$
- 配方中心：$y-\rho^{-1}H^{-1}\nabla f(y)$
- scaled PnP-FISTA：$x_{k+1}=\mathcal D(y_{k+1}-\rho^{-1}H^{-1}\nabla f(y_{k+1}))$
- 原则：`prox 换几何 → gradient / smoothness 也必须换到同一几何`

## Objective convergence

- 条件：$f$凸且在$H$几何中$\rho$-smooth；$W$满足 scaled-prox 条件；问题有 minimizer
- 结论：$F(x_k)-F^\star=O(1/k^2)$
- Chambolle–Dossal 型$t_{k+1}=1+k/a$、$a>2$：可进一步得到$x_k$收敛到 minimizer
- 边界：上述“迭代点收敛”不等于“迭代点线性收敛”

## Iterate convergence

- Sinha 2024 范围：线性逆问题 + 固定线性 denoiser
- 数据项：$f(x)=\frac12\lVert Ax-b\rVert_2^2$
- PnP 步：$x_k=W(I-\gamma A^TA)y_k+\gamma WA^Tb$
- 记$P_\gamma=W(I-\gamma A^TA)$ → 一次 PnP 是 affine map
- 动量使$x_k$依赖$x_{k-1},x_{k-2}$ → 升维状态$z_k=[x_k;x_{k-1}]\in\mathbb R^{2n}$

## 联合收缩条件

- $\sigma(W)\subset[0,1]$
- $\ker(A)\cap\operatorname{fix}(W)=\{0\}$
  - $d\in\ker(A)$：数据模块看不见$d$
  - $d\in\operatorname{fix}(W)$：denoiser 不改变$d$
  - 非零交集 → 存在`数据与 denoiser 都管不了`的方向
- 步长：$0<\gamma<1/\lambda_{\max}(A^TA)$

## 谱分析

- 状态递推：$z_k=R_kz_{k-1}+s$
- 若$\alpha_k\to1$：$R_k\to R_\infty$
- 核心：$\rho(R_\infty)<1$
- 结论：存在$0\le\beta<1$，$\lVert x_k-x^\star\rVert\le C\beta^k$
- `linear convergence`：几何衰减$\beta^k$，不是$1/k$

## 非对称 kernel denoiser

- 回到$D$-weighted geometry：$\langle x,y\rangle_D=x^TDy$
- $D$-gradient：$\nabla_D f(x)=D^{-1}A^T(Ax-b)$
- scaled PnP-FISTA：$x_k=W(y_k-\gamma\nabla_D f(y_k))$
- 步长：$0<\gamma<1/\lambda_{\max}(D^{-1/2}A^TAD^{-1/2})$

## 两种“快”

| 结论 | 衡量量 | 典型条件 |
| --- | --- | --- |
| FISTA / scaled PnP-FISTA 加速 | $F(x_k)-F^\star=O(1/k^2)$ | 能恢复合适的 proximal objective |
| Sinha 2024 线性收敛 | $\lVert x_k-x^\star\rVert\le C\beta^k$ | 线性 inverse problem + 特定线性 denoiser + 谱条件 |

- 动量可让 objective 最坏情形更快，但具体 iterate 不保证比 PnP-ISTA 更快

## 与 PnP-ADMM

- `PnP-ADMM`：data subproblem + denoiser + dual；$f$可更一般；data step 可能较重
- `PnP-FISTA`：gradient + denoiser + momentum；要求$f$光滑；每轮通常更轻
- 共同问题：denoiser 替换后，父算法理论不能无条件照搬
- 共同原则：先问`denoiser 属于什么数学类别`，再问`能声称什么收敛`
