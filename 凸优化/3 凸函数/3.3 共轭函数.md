# 3.3 共轭函数

## 3.3.1 定义

- 对函数$f:\mathbb R^n\to\mathbb R\cup\{+\infty\}$，`Fenchel 共轭`定义为
$$f^*(y)=\sup_{x\in\operatorname{dom}f}\left(y^Tx-f(x)\right),\qquad y\in\mathbb R^n.$$
- $\operatorname{dom}f^*$由使上确界有限的$y$组成。几何上，$f^*(y)$是斜率为$y$的线性函数$y^Tx$与$f(x)$之间的最大竖直间隙。
- 对每个固定$x$，$y\mapsto y^Tx-f(x)$是仿射函数；因此$f^*$是仿射函数族的逐点上确界，`无论原函数$f$是否凸，$f^*$总是凸函数`。
- 若$f$可微且上确界在$x^*$取得，驻点条件为
$$y=\nabla f(x^*).$$
  对闭凸可微函数，该条件也保证$x^*$是最大点，并有$f^*(y)=y^Tx^*-f(x^*)$。

## 常见共轭

| $f(x)$ | $\operatorname{dom}f^*$ | $f^*(y)$ |
| --- | --- | --- |
| $ax+b$ | $\{a\}$ | $f^*(a)=-b$ |
| $-\log x$，$x>0$ | $y<0$ | $-\log(-y)-1$ |
| $e^x$ | $y\ge0$ | $y\log y-y$，约定$0\log0=0$ |
| $x\log x$，$x\ge0$ | $\mathbb R$ | $e^{y-1}$ |
| $1/x$，$x>0$ | $y\le0$ | $-2\sqrt{-y}$ |
| $\frac12x^TQx$，$Q\in\mathbb S_{++}^n$ | $\mathbb R^n$ | $\frac12y^TQ^{-1}y$ |

### 对数行列式

- 令$f(X)=-\log\det X$，变量$X\in\mathbb S_{++}^n$，矩阵空间的内积为$\langle Y,X\rangle=\operatorname{tr}(YX)$。
- 共轭为
$$f^*(Y)=\sup_{X\succ0}\left(\operatorname{tr}(YX)+\log\det X\right).$$
- 若$Y\not\prec0$，目标沿某个非负特征方向无上界；若$Y\prec0$，矩阵梯度条件
$$Y+X^{-1}=0$$
  给出$X=-Y^{-1}\succ0$。因此
$$f^*(Y)=-\log\det(-Y)-n,\qquad\operatorname{dom}f^*=-\mathbb S_{++}^n.$$

### 指示函数与支撑函数

- 集合$S\subseteq\mathbb R^n$的指示函数$I_S$的共轭为
$$I_S^*(y)=\sup_{x\in S}y^Tx=S_S(y),$$
  即$S$的支撑函数。$S$不必凸，但其支撑函数仍凸。

### log-sum-exp 与负熵

- 对$f(x)=\log\sum_{i=1}^n e^{x_i}$，共轭是概率单纯形上的负熵：
$$f^*(y)=\begin{cases}\sum_{i=1}^n y_i\log y_i,&y\succeq0, \mathbf1^Ty=1,\\+\infty,&\text{其他情况}。\end{cases}$$
- 梯度关系$y_i=e^{x_i}/\sum_j e^{x_j}$说明：log-sum-exp 的对偶变量天然位于概率单纯形。

### 范数与对偶范数

- 若$\lVert\cdot\rVert_*$是$\lVert\cdot\rVert$的对偶范数，则
$$\bigl(\lVert\cdot\rVert\bigr)^*(y)=I_{\{y\mid\lVert y\rVert_*\le1\}}(y).$$
- 对范数平方，
$$f(x)=\frac12\lVert x\rVert^2\quad\Longrightarrow\quad f^*(y)=\frac12\lVert y\rVert_*^2.$$
- 关键边界是$\lVert y\rVert_*\le1$：若超过$1$，沿能达到对偶范数的方向放大$x$，$y^Tx-\lVert x\rVert$趋于$+\infty$。

## 3.3.2 基本性质

### Fenchel–Young 不等式

- 由上确界定义，对任意$x,y$都有
$$f(x)+f^*(y)\ge x^Ty.$$
- 等号表示$x$在$f^*(y)$的上确界中达到最大。若$f$闭、凸、可微，则等号等价于$y=\nabla f(x)$。
- 对$f(x)=\frac12x^TQx$、$Q\succ0$，得到
$$x^Ty\le\frac12x^TQx+\frac12y^TQ^{-1}y.$$

### 双共轭

- $f^{**}$总是闭凸函数；若$f$本身闭且凸，则
$$f^{**}=f.$$
- 闭性指$\operatorname{epi}f$是闭集。若省略闭性，双共轭一般得到$f$的闭凸包，而不一定逐点等于$f$。

### 梯度互逆关系

- 若$f$严格凸、可微且梯度映射可逆，则
$$y=\nabla f(x)\iff x=\nabla f^*(y).$$
- 此时
$$f^*(\nabla f(x))=x^T\nabla f(x)-f(x).$$
- 该关系说明共轭把“自变量—斜率”角色互换；严格凸性保证一个斜率通常只对应一个接触点。

### 变换规则

- 若$a>0$、$b\in\mathbb R$，$g(x)=af(x)+b$，则
$$g^*(y)=a f^*(y/a)-b.$$
- 若$A\in\mathbb R^{n\times n}$非奇异、$b\in\mathbb R^n$，$g(x)=f(Ax+b)$，则
$$g^*(y)=f^*(A^{-T}y)-b^TA^{-T}y,$$
$$\operatorname{dom}g^*=A^T\operatorname{dom}f^*.$$
- 若$f(u,v)=f_1(u)+f_2(v)$且两项依赖不同变量，则
$$f^*(w,z)=f_1^*(w)+f_2^*(z).$$
  “不同变量”是该简单求和规则的条件；同一变量上的函数和，其共轭一般涉及下卷积，不能直接逐项相加。

## 易错点

- `共轭总凸`不意味着原函数凸；共轭的凸性来自对$y$取仿射函数的上确界。
- `定义域由有界性决定`：只解驻点方程不足以确定共轭，还必须检查目标在其他$y$处是否无界。
- 矩阵变量的线性项使用$\operatorname{tr}(YX)$，且$X,Y\in\mathbb S^n$；$X^{-1}$只在$X\succ0$上定义。
- $f^{**}=f$需要闭性与凸性；只写“凸函数的双共轭等于自身”会漏掉边界条件。
